# StudyFlow

StudyFlow is a responsive SaaS landing page concept for a student study planner. It was created for the Sankar Group Front-End Development assignment using plain HTML, CSS, and JavaScript.

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern browser.

No build step, package installation, API key, or backend is needed. The Google Fonts link is optional; the page falls back to system fonts if you are offline.

## What’s included

- Responsive page sections for features, how it works, pricing, and contact.
- Working section navigation and an accessible mobile menu.
- A demo request form with name and email validation and an on-page success message.
- Illustrative planner preview built from HTML and CSS.

## Design and challenges

StudyFlow uses a warm, quiet palette and generous spacing to make the page feel calm and easy to scan.
The planner preview is built from HTML and CSS, so it stays sharp and adapts to screen size.
The page uses semantic sections and anchor links to make the information easy to navigate.
Feature cards, a three-step guide, and two plans explain the product without overwhelming visitors.
On small screens, the desktop navigation becomes a button-controlled menu.
The demo form checks the name and email in the browser, then displays a success message without a backend.
The page uses no account credentials, external APIs, or payment processing.
